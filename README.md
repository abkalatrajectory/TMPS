# TMPS

TMPS is a simple travel platform landing page inspired by services such as
MakeMyTrip. It highlights flight bookings, hotel stays, holiday packages, and
travel offers in a clean static website.

## Run locally

Open `/home/runner/work/TMPS/TMPS/index.html` in a browser, or serve the
repository with a simple static file server such as:

```bash
python -m http.server 8000
```
